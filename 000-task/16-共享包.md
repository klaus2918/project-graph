# 16 共享包

monorepo 包（`packages/`）：

```text
@graphif/serializer       实例序列化（reflect-metadata）
@graphif/shapes           可序列化图形
@graphif/data-structures  可序列化数据结构
extprg                    扩展 CLI 工具链
extprg-types              扩展 API 类型（生成）
create-extprg             扩展脚手架
```

## 1. @graphif/serializer

目录：`packages/serializer/`

### 1.1 装饰器

| 装饰器                                     | 作用                                                 |
| ------------------------------------------ | ---------------------------------------------------- |
| `@serializable`                            | 标记可序列化字段（按声明顺序编号，reflect-metadata） |
| `@id`                                      | 标记标识字段（如 uuid），用于引用登记                |
| `@passExtraAtArg1` / `@passExtraAtLastArg` | 反序列化构造时把 extra（Project）注入首/尾参数       |
| `@passObject`                              | 反序列化时直接传入整个 JSON 对象                     |

### 1.2 序列化规则

- 输出 `{ _: className, ...fields }`；数字保留 2 位小数；数组逐项处理；
- 引用：已序列化的 `@id` 对象再次出现时输出 `{ $: path }`（对象图共享）；
- 类注册表：`@serializable` 时登记 `getOriginalNameOf(constructor)`；
- `configureSerializer(fn)`：接入 `unplugin-original-class-name` 使压缩后类名仍可还原。

### 1.3 反序列化

- `deserialize(json, extra)`：按 `_` 查类、递归转换、`$` 引用替换（`getByPath`）、构造实例并缓存（WeakMap 保证同一对象只建一次）；
- 数组就地转换并缓存，保证共享引用一致。

## 2. @graphif/shapes

| 类                      | 说明                                                                              |
| ----------------------- | --------------------------------------------------------------------------------- |
| `Shape`                 | 抽象基类：`isPointIn / isCollideWithRectangle / isCollideWithLine / getRectangle` |
| `Rectangle`             | 矩形（location+size，包围盒、碰撞、包含、中心、重叠等）                           |
| `Circle`                | 圆                                                                                |
| `Line`                  | 线段                                                                              |
| `Curve`                 | 曲线基类（贝塞尔等）                                                              |
| `CubicCatmullRomSpline` | 三次 Catmull-Rom 样条                                                             |

用途：节点/边的碰撞箱、渲染几何、布局计算、导出。

## 3. @graphif/data-structures

| 结构                                           | 说明                                                                                   |
| ---------------------------------------------- | -------------------------------------------------------------------------------------- |
| `Vector`                                       | 二维向量（加减乘除、归一化、旋转、limit、distance、fromTouch、average…），舞台坐标基础 |
| `Color`                                        | RGBA 颜色（含 Transparent、混合 mixColors、反转等）                                    |
| `Queue / Stack / LimitLengthQueue / MonoStack` | 数据结构（相机轨迹队列、特效进度等）                                                   |
| `Cache`                                        | 通用缓存                                                                               |
| `ProgressNumber`                               | 进度数（特效时间轴、计数动画）                                                         |

## 4. extprg（扩展 CLI）

`packages/extprg/`：

- 命令：`build`（esbuild bundle → dist/extension.js + metadata.msgpack + README/icon）、`package`（zip）、`install`（安装到应用目录）、`dev`（开发监听）；
- `constants.ts`：`PRG_VERSION`、`DEFAULT_APP_ID`；
- `logger.ts`：彩色日志。

## 5. extprg-types

由 `extensionHostApiFactory` 生成的类型声明（`index.d.ts`）：`declare const prg` 暴露全部宿主 API（toast/dialog/fetch/shell/settings/keybinds/stage/entity/themes/ai/ui…），扩展开发获得完整 IntelliSense。

## 6. create-extprg

脚手架 CLI：生成模板工程（`src/extension.ts`、package.json、tsdown.config.ts、README、icon.svg），模板用 EJS 渲染。

## 7. 包之间依赖

```text
shapes → data-structures（Vector）
serializer：独立（reflect-metadata）
app → serializer / shapes / data-structures
extprg / create-extprg：独立工具链，输出 app 可加载的扩展包
```
