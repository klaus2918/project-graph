# 07 文件系统与工程文件格式

## 1. FileSystemProvider 抽象

接口定义：`app/src/core/interfaces/Service.tsx`

```ts
interface FileSystemProvider {
  read(uri: URI): Promise<Uint8Array>;
  readDir(uri: URI): Promise<DirEntry[]>;
  write(uri: URI, content: Uint8Array): Promise<void>;
  remove(uri: URI): Promise<void>;
  exists(uri: URI): Promise<boolean>;
  mkdir(uri: URI): Promise<void>;
  rename(oldUri, newUri): Promise<void>;
}
```

实现（`app/src/core/fileSystemProvider/`）：

| Provider                   | scheme   | 行为                                                                                      |
| -------------------------- | -------- | ----------------------------------------------------------------------------------------- |
| `FileSystemProviderFile`   | `file`   | 直接映射 Tauri `plugin-fs`                                                                |
| `FileSystemProviderDraft`  | `draft`  | `read` 返回空 ZIP；`write` 弹“另存为”对话框并把工程 URI 改为真实文件；`exists=false`      |
| `FileSystemProviderCollab` | `collab` | `read` 返回空 ZIP；`write` 抛错提示“另存为”；`exists=false`（加入房间时由服务端注入状态） |

## 2. .prg 工程文件格式

容器：ZIP（`@zip.js/zip.js`，压缩级别 0 防止保存卡顿）。

```text
stage.msgpack        # StageObject[] 序列化（MsgPack）
tags.msgpack         # string[]
reference.msgpack    # { sections: Record<string,string[]>, files: string[] }
metadata.msgpack     # { version, extension? }
README.md            # 可选
attachments/<uuid>.<ext>  # 附件（mime 由扩展名推断）
thumbnail.png        # 可选（保存时生成，失败不阻塞）
```

读写实现：

- `Project.getFileContent()`：`serialize(stage)` → MsgPack `Encoder` → 逐项写入 ZIP → 可选缩略图；
- `Project.parseProjectFile()`：`ZipReader` 解包 → `Decoder` 解码 → metadata 校验（`isValidMetadata`）→ 附件按 UUID 载入；
- 扩展包复用同一容器：`extension.js` + `metadata.msgpack` + `README.md` + 图标（见第 11 篇）。

## 3. 序列化（@graphif/serializer）

详见第 16 篇。要点：

- 装饰器标记可序列化字段：`@serializable`、`@id`（引用登记）、`@passObject` / `@passExtraAtArg1/LastArg`（反序列化构造参数）；
- 序列化输出 `{ _: className, ...fields }`，重复对象用 `{ $: path }` 引用，保证对象图（如边两端的实体引用）在文件里只出现一次；
- 反序列化按 className 查注册表构造实例并修复引用。

## 4. 自动保存与备份（AutoSaveBackupService）

`@service("autoSaveBackup")`，tick 驱动：

- 自动保存：`autoSave` + `autoSaveInterval`（仅非草稿且 Unsaved 时），`includeThumbnail: false`；
- 自动备份：`autoBackup` + `autoBackupInterval` + `stageHash` 去重；
- 备份策略（`autoBackupStrategy`）：
  - `default`：写入数据目录（`~/.local/share/liren.project-graph/` 或 Windows AppData 备份文件夹），支持主/备自定义路径；
  - `sideBySide`：原文件旁 `{file}_backup_{timestamp}.prg`；
  - `subfolder`：原文件旁 `{file}_backup/{timestamp}.prg`；
- 清理：按 `autoBackupLimitCount` 删除最旧备份。

## 5. 最近文件与启动文件

- `RecentFileManager`：`recent-files2.json`（Tauri store），去重、时间排序、`validAndRefreshRecentFiles()` 校验文件存在性并清理失效项；
- `StartFilesManager`：启动时恢复上次打开的文件列表；
- `ReferenceFileScanner`：扫描工程引用文件（供引用面板/检查用）。

## 6. 深链与系统打开（DeepLinkHandler）

- 协议：`prg://open?path=...&location=x,y&zoom=z&target=uuid`；
- `createCurrentFileDeepLink / createCurrentViewDeepLink / createSelectedEntityDeepLink`：生成链接（含相机视图/选中对象）；
- `handleDeepLink`：解析路径（支持绝对路径、`/D:/` Windows 形式、相对路径在最近文件中搜索）→ 打开文件并应用位置/缩放/目标；
- `main.tsx` 处理：CLI 参数、`take_pending_open_files`（macOS 双击）、`listen("open-file-from-os")`、deep link 冷/热启动（`getCurrent` + `onOpenUrl`）；
- Tauri 侧注册 `prg` scheme、`.prg` 文件关联（`tauri.conf.json`）。

## 7. 缩略图与截图

- `generateThumbnail.tsx`：保存时生成工程缩略图（`readPrgThumbnail.ts` 读取缓存）；
- `generateScreenshot.tsx`：运行时截图；
- `utils/imageExport.tsx`：导出图片到工程目录；
- `utils/readPrgThumbnail.ts`：从 `.prg` 快速读取 thumbnail.png（最近文件列表显示用）。

## 8. 文本文件导入

`TextFileImporter.tsx`：把 `.txt/.md` 等内容按行/缩进转换为舞台节点树。
