# 09 数据管理服务

相关目录：`app/src/core/service/dataManageService/`

```text
dataManageService/
  contentSearchEngine/        # 内容搜索
  copyEngine/                 # 复制/粘贴
  dragFileIntoStageEngine/    # 拖文件进舞台
  aiEngine/                   # AI（见第 10 篇）
  colorSmartTools.tsx         # 智能配色
  connectNodeSmartTools.tsx   # 智能连线
  textNodeSmartTools.tsx      # 文本节点智能工具
  imageNodeFactory.ts         # 图片节点工厂
  imageUtils.tsx              # 图片工具
  ComplexityDetector.tsx      # 舞台复杂度检测
```

## 1. 内容搜索（ContentSearch）

`@service("contentSearch")`：

- 范围：`SearchScope.ALL / SELECTED / SELECTED_BOUNDS`；
- 大小写敏感开关；
- 抽取可搜索文本：TextNode（text + details）、Section、UrlNode（title + details + url）、Edge（边文字）、任意实体的 details；
- 结果列表 + 当前索引，`SearchContentHighlightRenderer` 在画布上高亮命中项（帧动画）；
- 搜索 UI 由 `sub/FindWindow.tsx` 提供（停靠左栏）。

## 2. 复制/粘贴（CopyEngine）

`@service("copyEngine")`：

### 2.1 虚拟剪贴板（VirtualClipboard）

独立于系统剪贴板的内存存储：因为 Tauri 剪贴板（arboard）无法写入自定义 MIME，复制舞台对象必须走虚拟剪贴板（序列化对象 + 附件 Map）。

### 2.2 复制（copy）

```text
取选中实体 → 收集关联对象（CopyEngineUtils.getAllStageObjectFromEntities）
→ 收集附件（图片/SVG）
→ serialize 存入 VirtualClipboard
→ 特效反馈（RectangleNoteReversedEffect）
→ 同步系统剪贴板：
   单张图片 → writeImage
   文本节点 → writeText（\n\n 连接）
→ 清空选中
```

### 2.3 粘贴（paste）

- 有虚拟剪贴板数据：反序列化 → 重新生成 UUID（`copyEngineUtils` 内 `v4`）→ 偏移放置；
- 否则走系统剪贴板：文本/图片/HTML 等（`CopyEngineText` / `CopyEngineImage`），粘贴模式 `clipboardPasteMode`（auto/webview/tauri）；
- 图片粘贴：压缩 WebP、黑白阈值、最大尺寸、可选包进 Section（`wrapImageInGroup`）。

## 3. 拖文件进舞台（DragFileIntoStageEngine）

监听系统拖入：图片 → 图片节点（`imageNodeFactory`），文本/支持格式 → 文本节点或文本导入，按落点创建实体。

## 4. 图像工具

- `imageNodeFactory.ts`：从 Blob 创建 ImageNode（计算展示尺寸 `calculateImageDisplaySize`、压缩 `prepareImageBlobForImport`）；
- `imageUtils.tsx`：Blob → dataURL、压缩（webpQuality/黑白阈值）；
- AI 图像：`aiEngine/imageNodeFinder.ts`（在节点 children 中找第一张图）、`aiEngine/OpenverseImageSearch.ts`（Openverse 图片搜索 API，供 AI 搜图建节点）。

## 5. 复杂度检测（ComplexityDetector）

`@service("complexityDetector")`：统计舞台规模（节点数/边数/Section 深度等），供性能提示/自动降级参考。

## 6. 智能工具

- `colorSmartTools.tsx`：按语义/类别给对象自动配色；
- `connectNodeSmartTools.tsx`：自动连接智能补全（按距离/结构猜测连线目标）；
- `textNodeSmartTools.tsx`：文本节点批量操作（统一字号/格式等）。

## 7. 与 AI 引擎的关系

`aiEngine/` 中的工具集（AITools）直接调用上述能力（创建/编辑节点、搜索、批量改色、图像识别等），详见第 10 篇。
