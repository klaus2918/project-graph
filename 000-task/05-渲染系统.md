# 05 渲染系统

相关目录：

```text
app/src/core/render/
  canvas2d/          # 主渲染：renderer + basic/controller/entity/utils 渲染器
  svg/               # SVG 导出工具
  domElement/        # DOM 叠加元素（输入框、矩形元素）
  3d/                # 预留（README 说明）
```

## 1. 渲染架构（canvas2d）

官方 README 定义的层次：

```text
第一层 基础渲染器   basicRenderer    画线/矩形/圆/文本/图片/SVG
第二层 通用组件渲染 controllerRenderer 绘制控制器交互临时内容（切割线、连线、笔迹绘制等）
第三层 业务组件渲染 entityRenderer   针对各种节点/边/Section 的具体渲染
辅助    utilsRenderer  背景、搜索高亮、RenderUtils、WorldRenderUtils
```

### 1.1 Renderer（总入口，`renderer.tsx`）

`@service("renderer")`，核心职责：

- 视口管理：`w/h`、`resizeWindow()`（按 devicePixelRatio 设置 canvas 物理尺寸并 scale ctx）；
- 渲染循环入口 `tick()`：支持 `isPauseRenderWhenManipulateOvertime`（长时间无操作暂停重渲染）；
- 渲染顺序：

```text
updateFPS
renderBackground（背景网格/点/笛卡尔坐标）
renderMainStageElements(viewRectangle)
  ├── entityRenderer.renderAllSectionsBackground（Section 背景）
  ├── renderEntities
  ├── renderEdges（先实体后连线，线压在图片上）
  ├── renderAllSectionsBigTitle（折叠大标题）
  ├── renderTags
  ├── drawingControllerRenderer.renderTempDrawing（临时绘制）
  ├── hover collision box / 框选矩形 / 切割线 / 连线 / 键盘模式高亮 / 层移动线
  └── searchContentHighlightRenderer.render
GlobalMaskRenderer（隐私模式蒙版）
renderViewElements（快捷键提示、中心准星、缩放档位 Z 级、debug 信息）
```

### 1.2 视口变换

`Renderer` 提供世界↔视图坐标转换：

- `transformWorld2View(world)`：减去相机位置、乘缩放；
- `transformView2World(view)`：逆变换；
- `getCoverWorldRectangle()`：当前视口覆盖的世界矩形（渲染裁剪与导出遍历使用）；
- `isOverView(rect, obj)`：视口外剔除。

## 4. 控制器渲染与工具（controllerRenderer / utilsRenderer）

- `drawingRenderer.tsx`：切割、连线、笔迹绘制等临时交互内容；
- `backgroundRenderer.tsx`：网格/点/坐标轴背景（水平线、垂直线、点、笛卡尔坐标开关）；
- `searchContentHighlightRenderer.tsx`：搜索命中高亮（按帧动画闪烁）；
- `RenderUtils.tsx` / `WorldRenderUtils.tsx`：渲染工具函数（世界/视图单位换算等）；
- `debugRender.tsx`：调试信息；
- `globalMaskRenderer.tsx`：隐私模式蒙版（`Settings.stealthModeReverseMask`）。

## 5. SVG 渲染（render/svg）

- `SvgUtils.tsx`：把画布对象转成 SVG 元素/字符串；
- `StageExportSvg`（service）使用 ReactDOMServer 把节点渲染为 SVG，支持图片三种模式（absolutePath / relativePath / base64）；
- `cli.tsx` 的 `-o out.svg` 出口预留了该能力（当前占位）。

## 6. DOM 叠加渲染（render/domElement）

| 文件                   | 职责                                                                        |
| ---------------------- | --------------------------------------------------------------------------- |
| `inputElement.tsx`     | 临时 `<input>`：透明贴在画布上解决 Canvas 无法输入问题（Esc/失焦/滚轮结束） |
| `RectangleElement.tsx` | DOM 矩形元素（例如框选/高亮的 DOM 版本）                                    |

## 8. 渲染循环与性能

- rAF 循环由 `Tab.loop()` 驱动（见第 03 篇），`Renderer.tick` 是其中一个服务 tick；
- `Settings.maxFps / maxFpsUnfocused` 控制帧率；`pauseRenderWhenTabUnfocused` 让非活动标签暂停；
- 画布 mousemove 会唤醒循环，避免静止时空转；
- 渲染裁剪：只渲染与当前视口相交的对象；
- 文本渲染优化：小于阈值的字号跳过细节（`ignoreTextNodeTextRenderLessThanFontSize`）。

## 9. 导出渲染

- PNG：`StageExportPng` 以视口为单位分块截屏（移动相机 → getImageData → 拼接到离屏 canvas），带进度事件与 AbortSignal；
- SVG：`StageExportSvg`（见上）；
- 缩略图：`dataGenerateService/generateThumbnail.tsx` 保存时生成（失败不阻塞保存）。
