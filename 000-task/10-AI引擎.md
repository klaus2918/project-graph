## 1. AIEngine（主服务）

`@service("aiEngine")`，为每个 Project 提供 AI 能力：

### 1.1 Provider 与传输

- 模型：OpenAI Compatible（`createOpenAICompatible`），baseURL/apiKey/model 全部来自 `Settings`（默认 Gemini OpenAI 端点 + gemini-2.5-flash）；
- 网络：走 Tauri `plugin-http`（绕过 CORS，能力配置允许任意 URL）；
- 传输：AI SDK `DefaultChatTransport` 拦截 `/api/project-graph-ai-chat` 请求；
- 中间件：`wrapLanguageModel` 的 `wrapGenerate/wrapStream` 记录每次模型调用的请求追踪（`AIRequestTraceBuffer`，最多 20 个 run）；
- 上下文窗口：`Settings.aiContextWindow` + `AIModelContextWindow` 估算，超出触发会话压缩。

### 1.2 会话记忆

- `AIChatSessionStore`：按 `projectUri + sessionId` 持久化（压缩摘要、激活的 Skills、消息）；
- `AIChatSessionMemory`：`createSessionMemoryCompactionPlan` 决定哪些消息需要压缩、生成摘要（用同一模型，maxOutputTokens 受限），压缩后保留摘要 + 未覆盖消息；
- 系统提示由 `composeAgentSystemPrompt(SYSTEM_PROMPT, skillContext, memoryContext)` 组合。

### 1.3 工具合并

```text
tools = mergeAgentToolSets(
  AITools.createTools(project, references),   // 舞台工具
  mcpRuntime.tools,                            // MCP 工具（含审批）
  skillTools,                                  // Skill 工具
)
```

## 2. AITools（舞台工具集）

工具名（源码实际注册）：

```text
get_all_nodes            delete_node               delete_nodes
delete_selected_nodes    delete_all_nodes          edit_text_node
edit_image_node          auto_layout_dag           create_text_node
generate_node_tree_by_text  expand_node_tree_from_node
search_text_nodes_by_regex  get_children           get_parents
batch_change_color       get_object_details        check_connections
create_edges             change_edge_text          select_objects
get_selected_nodes       get_nodes_in_viewport     get_selected_refs
breadth_expand_node      depth_expand_node
sort_selected_nodes_by_y sort_selected_nodes_by_x
search_and_add_image_node  recognize_image
```

特点：

- 参数用 zod 严格校验（对象引用必须是 `n<数字>` / `e<数字>`）；
- 返回值用 `@toon-format/toon` 编码（结构化、可序列化），对象引用错误返回结构化错误码；
- 工具直接操作真实 Project（创建/移动/改色/连线/布局），通过 `HistoryManager` 记录；
- `search_and_add_image_node` 用 Openverse 搜索图片并建节点；`recognize_image` 调 Rust PaddleOCR-VL 命令（见第 15 篇）。

## 3. 对象引用（AIObjectReferenceRegistry）

- 把舞台对象映射为 `n1/n2...`（节点）、`e1/e2...`（边）的会话级引用；
- 提供对象信息序列化（碰撞箱矩形、文本、颜色、details 摘要）给模型；
- `AIProjectReferenceStore` 维护项目级引用持久状态。

## 4. Skills 系统（AISkills / AISkillSession）

让 AI 使用项目的 `SKILL.md`：

- 作用域：`user`（用户目录）与 `project`（工程目录）；
- 解析：YAML frontmatter（name 必须小写连字符且与目录同名、description 必填、body 非空），限制文件大小 256KB、资源深度 5、资源数 200；
- 信任机制：`ai-skill-trust.json`（LazyStore），项目级 Skill 需用户信任后可用；
- 激活：会话内按需激活（`activateSkill`），`filterActivatedSkillSnapshots` 在项目未被信任时过滤；
- 工具化：每个 Skill 生成一个工具（读取其 body/resources 交给模型）。

## 5. MCP 集成（AIMCP\*）

- 配置：`AIMCPConfig` 支持 stdio 与 streamable-http 两种 transport；`AIMCPStore` 持久化；配置文档可解析/序列化（`parseMCPConfigDocument`）；
- stdio：前端 `AIMCPStdio` 通过 Tauri `invoke` 调 Rust `mcp_stdio_start/list_tools/call_tool/stop`（Rust 侧 `rmcp` 管理子进程）；
- HTTP：`@ai-sdk/mcp` 的 `createMCPClient` + Tauri fetch；
- 工具名规范：`mcp__<server>__<tool>`（超长截断 + md5 防碰撞）；
- 审批：`aiAutoApproveMcpTools` 为 false 时所有 MCP 工具 `needsApproval = true`（UI 弹审批）；
- 工具选择：按 enabledTools 过滤。

## 6. 请求追踪（AIRequestTrace）

- `AIRequestTraceBuffer`（20 run 环形缓冲）：记录 run（会话/模型/消息）、wire 请求（URL/body/状态）、模型调用（generate/stream）、错误；
- UI：`sub/AIRequestTraceView.tsx` 与设置页 `local-ai.tsx` 展示。

## 7. AI 子窗口

- `sub/AIWindow.tsx`：AI 对话面板（默认停靠右侧）；
- `sub/AIToolsWindow.tsx`：工具管理（MCP 服务器开关、工具审批）；
- `sub/AutoCompleteWindow.tsx`：AI 自动补全面板。

## 8. 相关设置

`aiApiBaseUrl / aiApiKey / aiModel / aiContextWindow / aiShowTokenCount / enableOCR / aiAutoApproveMcpTools`，见 `Settings.tsx` schema。
