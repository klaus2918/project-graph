# 02 应用壳与全局状态

## 1. 入口文件

| 文件                          | 职责                                                                   |
| ----------------------------- | ---------------------------------------------------------------------- |
| `app/src/main.tsx`            | 进程级引导：初始化单例、加载语言、认证、渲染、打开启动文件             |
| `app/src/App.tsx`             | 主窗口外壳：菜单栏、窗口控制、标签页容器、右键菜单、命令面板、关闭保护 |
| `app/src/state.tsx`           | Jotai 全局 store 与全部全局 atom                                       |
| `app/src/cli.tsx`             | 无头 CLI 模式（`prg <file> -o out.svg`），当前仅输出帮助/占位          |
| `app/src/Fallback.tsx`        | React ErrorBoundary 兜底 UI                                            |
| `app/src/ProjectTabs.tsx`     | 标签页条（顶部标签 UI）                                                |
| `app/src/DropWindowCover.tsx` | 拖放文件到窗口时的遮罩                                                 |

## 2. 启动引导（main.tsx）

### 2.1 初始化顺序

```text
getMatches() → 判断 CLI 模式
Promise.all([RecentFileManager.init(), StartFilesManager.init(), ColorManager.init(),
             Tutorials.init(), UserState.init(), QuickSettingsManager.init(),
             ExtensionManager.init()])
Promise.all([loadLanguageFiles(), loadSyncModules(), initAuth()])
renderApp(isCliMode)
loadStartFile()            // CLI 参数 / 待打开队列 / macOS 双击 / deep link
ensureStartupDraftAndWelcome()  // 无标签页时：新建草稿 + 欢迎窗口
```

`loadSyncModules` 初始化：`EdgeCollisionBoxGetter`（边的碰撞箱缓存）与 `MouseLocation`（全局鼠标位置单例）。

### 2.2 CLI 模式

当桌面端 CLI 参数 `output` 出现时：隐藏主窗口、跳过任务栏、渲染空根组件、执行 `runCli`（当前 SVG 导出为占位实现），随后 `exit()`。CLI 参数：`path`（位置参数）、`output -o`、`size -s`。

## 3. App 主外壳

`App.tsx` 是唯一顶层 React 组件，职责：

- 恢复窗口状态（位置/大小/最大化），监听窗口尺寸变化；
- 注册 UI 级快捷键（`KeyBindsUI.registerAllUIKeyBinds`）与全局快捷键（`globalShortcutManager`）；
- 拦截浏览器默认行为（右键菜单、Ctrl+F/G/R 等）；
- 监听主题/主题模式/窗口透明度/UI 缩放设置变化；
- 标签页渲染循环调度：`pauseRenderWhenTabUnfocused` 时只驱动活动资源标签页，否则驱动全部；
- 关闭窗口保护：检测未保存工程（Unsaved/Stashed），弹 Dialog 询问后再逐个关闭标签页；
- 最后一个工程关闭后自动新建草稿并打开欢迎窗口。

UI 结构（三层叠加）：

```text
最底层：窗口背景 div（透明度由 windowBackgroundAlpha 控制，不随 UI 缩放）
中间层：DockedArea（停靠标签组渲染）
顶层  ：zoom 缩放的 UI 层（菜单栏、右键菜单、命令面板、RenderOverlays）
        + 不缩放层：FloatingTabs（悬浮窗口）、PieMenu（饼图菜单）、DropWindowCover
```

关键点：**UI 缩放（Settings.uiScalePercent）只作用于 DOM UI 层，不影响 Canvas 画布**，保证画布坐标计算稳定。

## 4. 全局状态（state.tsx）

使用 Jotai `createStore()` 创建唯一 `store`，导出以下 atom：

| atom                                               | 类型                    | 说明                                          |
| -------------------------------------------------- | ----------------------- | --------------------------------------------- |
| `tabsAtom`                                         | `Tab[]`                 | 全部标签页（停靠 + 悬浮）                     |
| `activeTabAtom`                                    | `Tab \| undefined`      | 当前聚焦标签（含 UI 面板）                    |
| `tabGroupRootAtom`                                 | `TabGroupNode \| null`  | 停靠区布局树（group/split 二叉树）            |
| `activeGroupIdAtom`                                | `string \| undefined`   | 当前活动停靠组                                |
| `tabDropTargetAtom`                                | `TabDropTarget \| null` | 拖放预览目标                                  |
| `activeDockedTabAtom`                              | 派生                    | 活动停靠标签                                  |
| `resourceTabsAtom` / `activeResourceTabAtom`       | 派生                    | 资源型标签（有 URI 的 Tab）与当前活动资源标签 |
| `isClassroomModeAtom`                              | `boolean`               | 教室模式（隐藏 UI）                           |
| `nextProjectIdAtom`                                | `number`                | 草稿序号                                      |
| `isWindowAlwaysOnTopAtom` / `isWindowMaxsizedAtom` | `boolean`               | 窗口状态                                      |
| `isClickThroughEnabledAtom`                        | `boolean`               | 窗口点击穿透                                  |
| `isDevAtom`                                        | `boolean`               | 开发模式                                      |
| `currentUserAtom` / `isAuthLoadingAtom`            | 认证                    | 当前登录用户与加载态                          |
| `commandPaletteVisibleAtom`                        | `boolean`               | 命令面板可见性                                |

## 5. 错误处理与兜底

- 顶层 `ErrorBoundary`（`Fallback.tsx`）捕获渲染错误；
- `window.error` 监听会上报遥测（`Telemetry.event("未知错误", …)`）；
- 服务 `tick()` 抛错时：从 tick 列表移除该服务、弹 Dialog 展示错误、上报遥测（`Tab.tick` 内实现）；
- 前端错误处理规范：不静默吞错，能向上抛就向上抛，需要提示时用 Dialog/toast（见 AGENTS.md）。

## 6. 其他全局服务入口

`main.tsx` 中直接引用的全局单例：

- `Settings` — 设置（见第 12 篇文档）；
- `QuickSettingsManager` — 快捷设置工具栏；
- `RecentFileManager` / `StartFilesManager` — 最近文件与启动文件；
- `ColorManager` — 颜色面板数据；
- `Tutorials` — 教程完成状态；
- `UserState` — 登录会话持久化；
- `ExtensionManager` — 扩展加载（详见第 11 篇）。
