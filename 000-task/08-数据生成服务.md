# 08 数据生成服务

相关目录：`app/src/core/service/dataGenerateService/`

```text
dataGenerateService/
  stageImportEngine/         # 导入（文本 → 舞台）
  stageExportEngine/         # 导出（舞台 → 文本/SVG/PNG）
  autoComputeEngine/         # 逻辑节点自动计算
  dataTransferEngine/        # 其他软件数据转换（XMind）
  generateFromFolderEngine/  # 文件夹 → 图/树
  TextFileImporter.tsx       # 文本文件导入
  crossFileContentQuery.tsx  # 跨文件内容查询
  generateScreenshot.tsx / generateThumbnail.tsx
```

## 1. 导入引擎（StageImport）

`@service("stageImport")`，聚合四个导入器（均继承 `BaseImporter`）：

| 导入器             | 输入格式                            | 说明                                              |
| ------------------ | ----------------------------------- | ------------------------------------------------- |
| `GraphImporter`    | `A --> B`、`A -label-> B`、独立节点 | 文本 → 网状结构                                   |
| `TreeImporter`     | 缩进文本（空格/Tab）                | 文本 → 树；支持从指定节点生长（`importFromNode`） |
| `MarkdownImporter` | Markdown 标题层级（#/##/###）       | 标题 → 树，可自动布局                             |
| `MermaidImporter`  | `graph TD` 类 Mermaid 文本          | → 带 Section 的网图                               |

## 2. 导出引擎（StageExport）

`@service("stageExport")`（不含图片导出）：

| 导出器              | 输出                                               |
| ------------------- | -------------------------------------------------- |
| `PlainTextExporter` | 节点列表 + `A --> B` 边列表                        |
| `MarkdownExporter`  | 文本节点及其子树 → 层级 Markdown（标题 + details） |
| `TabExporter`       | 缩进文本（树形）                                   |
| `MermaidExporter`   | `graph TD` + subgraph                              |

图片导出：

- `StageExportPng`：分块截图拼接（可中断、带进度）→ Blob；
- `StageExportSvg`：ReactDOMServer 渲染 SVG，图片引用模式可配置（绝对路径/相对路径/base64）。

## 3. 自动计算引擎（AutoCompute）

`@service("autoCompute")`：把连成一棵逻辑图的节点当作表达式/程序执行：

```text
父节点(函数) → 子节点(参数) → 结果写回父节点文本
```

函数库：

- 数学：四则、幂、取整、sqrt/log/三角函数、统计（count/ave/median/mode/variance/std/random…）；
- 比较：`< > <= >= == !=`、逻辑与或非异或；
- 字符串：upper/lower/len/copy/split/replace/connect/regex；
- 编程：SET_VAR / GET_VAR 变量；
- 节点/舞台：RGB/RGBA 上色、获取/设置位置大小、相机位置、鼠标位置等。

实现：`mainTick.tsx` 维护符号→函数映射（`MapOperationNameFunction/MapNameFunction/MapVariableFunction/MapOtherFunction`），`functions/` 目录按类别实现（compare/math/node/program/string），`AutoComputeUtils` 提供配套工具。结果变化时触发特效与舞台刷新。

## 4. 从文件夹生成（GenerateFromFolder）

`@service("generateFromFolder")`：

- `generateFromFolder(path)`：文件夹 → Section 嵌套结构（文件为 TextNode，文件夹为 Section，details 存路径，按扩展名配色）；
- `generateTreeFromFolder(path)`：文件夹 → 平面树（TextNode + LineEdge，父子按 150/50 间距排布）。

底层调用 Rust 命令 `read_folder_structure` 递归读取目录。

## 5. 数据转换与跨文件

- `DataTransferEngine.xmindToString`：XMind zip 的 content.json → 缩进文本（可再走 TreeImporter）；
- `crossFileContentQuery.tsx`：跨多个工程文件查询内容（引用/搜索场景）；
- `TextFileImporter.tsx`：文本文件内容导入为节点。
