# 03 标签页与工程生命周期

相关文件：

```text
app/src/core/Tab.tsx             # Tab / ComponentTab / ResourceTab
app/src/core/TabGroup.ts         # 停靠布局树纯函数
app/src/core/TabWorkspace.tsx    # 标签页打开/关闭/停靠/悬浮/分屏
app/src/core/TabFactory.tsx      # 按文件内容识别 Project 或 Extension
app/src/core/Project.tsx         # 工程类 + service 装饰器
app/src/core/TestTab.tsx         # 测试标签页
```

## 1. Tab 基类

`Tab` 继承 `React.Component`（每个标签页同时是一个 React 组件），并提供：

### 1.1 标签属性

| 属性                                                                                                  | 说明                                        |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| `id`                                                                                                  | `crypto.randomUUID()`                       |
| `layout`                                                                                              | `"docked" \| "floating"`                    |
| `floatingRect`                                                                                        | 悬浮窗口矩形（`@graphif/shapes` Rectangle） |
| `zIndex`                                                                                              | 悬浮层级                                    |
| `closing`                                                                                             | 关闭中标记                                  |
| `canDock / closable / closeOnEscape / closeWhenClickOutside / closeWhenClickInside / titleBarOverlay` | 窗口行为选项                                |

### 1.2 服务容器

```ts
loadService(service: { id?: string; new (...args): any })
```

- 若未指定 `id` 自动生成 UUID 并警告；
- 实例化 `new service(this)`，存入 `services` Map；
- 有 `tick` 方法的服务进入 `tickableServices`；
- 实例同时挂在 `(this)[service.id]`，使 `project.stageManager`、`project.renderer` 等访问路径成立。

`disposeService(serviceId)` 反向卸载；`dispose()` 并行 `Promise.allSettled` 全部服务。

### 1.3 渲染循环

```ts
loop()  // 注册 requestAnimationFrame
  → 按 Settings.maxFps / maxFpsUnfocused 计算 timeStep
  → 每帧最多补 10 个 tick，防止追赶风暴
  → 依次调用 tickableServices[i].tick()
pause() // cancelAnimationFrame
```

### 1.4 文件系统访问

`registerFileSystemProvider(scheme, provider)` 按 URI scheme 注册：

```text
file:  → FileSystemProviderFile（真实文件）
draft: → FileSystemProviderDraft（内存草稿，首次保存弹“另存为”）
collab:→ FileSystemProviderCollab（协作会话，保存即“另存为”）
```

`tab.fs` getter 根据 `uri.scheme` 返回对应 provider，URI 使用 `vscode-uri`。

### 1.5 事件

基于 Node `events` EventEmitter 的代理方法：`on/off/emit/removeAllListeners`。工程常用事件：

- `state-change`（保存状态/保存中变化）
- `contextmenu`（标签右键）
- `stage-commit`（舞台提交，协作服务监听）
- `collab-state` / `collab-status`（协作状态）

## 2. ComponentTab（UI 子窗口）

`ComponentTab` 是轻量标签：构造函数接收 `ComponentTabOptions`（title、icon、children、layout、splitEdge、rect、行为选项），生成一个渲染 children 的 React 组件。子窗口系统（`createSubWindow`）就是它的工厂封装。

## 3. ResourceTab 与 TabFactory

- `ResourceTab`：带 `uri` 的 Tab（Project / Extension）；
- `TabFactory.create(uri, fs)`：读取 zip 包内文件名，含 `stage.msgpack` → `Project`，含 `extension.js` → `Extension`，默认 Project。

## 4. Project 工程

### 4.1 状态机

```text
ProjectState:
  Saved   已写入原始文件
  Stashed 未写入原文件，但已暂存到数据目录（当前 stash() 为 TODO 占位）
  Unsaved 未保存
```

`projectState` 变化时 emit `state-change`，`App` 据此强制刷新标签列表。

### 4.2 工程文件（.prg）

`Project` 维护：

| 字段          | 内容                                                              |
| ------------- | ----------------------------------------------------------------- |
| `stage`       | `StageObject[]` 舞台对象数组                                      |
| `tags`        | `string[]` 标签                                                   |
| `references`  | 反向引用 `{ sections: Record<string,string[]>, files: string[] }` |
| `metadata`    | `PrgMetadata`（version + 可选 extension）                         |
| `readme`      | 可选 README.md                                                    |
| `attachments` | `Map<uuid, Blob>` 附件（图片/音频/文件等）                        |

读写流程（`getFileContent` / `parseProjectFile`）：

```text
ZIP(level=0) 容器内：
  stage.msgpack     序列化舞台（@graphif/serializer + MsgPack）
  tags.msgpack
  reference.msgpack
  metadata.msgpack
  README.md         可选
  attachments/<uuid>.<ext>  可选
  thumbnail.png     可选（保存时生成）
```

版本升级：`ProjectUpgrader`（NLatestVersion = "2.6.0"）支持从 1.x JSON 逐级升级到最新；文件版本高于软件版本时拒绝打开并提示。

### 4.3 初始化（init）

```text
fs.exists(uri) → parseProjectFile()
→ 版本确认（过新拒绝 / 过旧确认升级）
→ ProjectUpgrader.upgradeNAnyToNLatest
→ deserialize(stage) 还原对象实例
→ stageManager.updateReferences()（修复 unknown 引用、重建 Section 树、边几何分组）
→ projectState = Saved
```

打开失败时弹 Dialog（可复制错误信息），不中断应用。

### 4.4 保存

- `save({ includeThumbnail })`：写 ZIP 到 `fs`；草稿 provider 会转成“另存为文件”；
- `stageHash`：stage 序列化 + MsgPack 编码后 md5，供自动备份去重；
- `isSaving` 标志参与 `state-change` 通知。

### 4.5 容器组件

`Project.getComponent()` 返回 `ProjectContainer`：

```text
绝对定位容器
  ├── div(ref=canvas mount 点)
  ├── ToolbarContent（顶部工具栏）
  └── RightToolbar（快捷设置侧栏，按设置显示）
```

## 6. 标签布局：TabGroup / TabWorkspace

### 6.1 布局树

```text
TabGroupNode = TabGroup | TabSplit
TabGroup  { id, type:"group", tabIds[], activeTabId? }
TabSplit  { id, type:"split", direction: horizontal|vertical, children:[L,R], sizes:[a,b] }
```

两个固定侧边组：`pg-side-left`、`pg-side-right`，子窗口停靠默认模式会复用它们（见第 14 篇）。`TabGroup.ts` 全部为纯函数：`getTabGroups / findTabGroup / insertTabIntoGroup / removeTabFromGroups / splitTabGroup / updateTabSplitSizes`。

### 6.2 TabWorkspace API

| 方法                                             | 行为                                                                                   |
| ------------------------------------------------ | -------------------------------------------------------------------------------------- |
| `open(tab)`                                      | 入 tabsAtom、分配 zIndex、加入布局树、聚焦；`closeWhenClickOutside` 时注册外部点击监听 |
| `create(options)`                                | 构造 ComponentTab 并按 splitEdge 停靠/分屏                                             |
| `focus(id)`                                      | 提升 zIndex、设置 active 系列 atom、更新组 activeTabId                                 |
| `dock / float / moveTab / split / resizeSplit`   | 布局变换                                                                               |
| `close(id)`                                      | 标记 closing、移除布局、450ms 后 dispose、500ms 后从 tabsAtom 移除（动画过渡）         |
| `closeAllFloating()`                             | 关闭全部可 ESC 关闭的悬浮窗口                                                          |
| `getDropTarget / previewDrop / clearDropPreview` | 拖放目标命中（四边 25%/100px 判定 + 标签条索引）                                       |

`TabWorkspace.synchronizeGroups()` 会把新加入的 docked 标签自动补入布局树（App 在 tabs 变化时调用）。
