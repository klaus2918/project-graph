# 11 扩展系统

相关目录：

```text
app/src/core/extension/
  Extension.tsx                # 扩展标签页（读包/元数据/图标/管理 UI）
  ExtensionManager.tsx         # 扩展发现/缓存/卸载/重载
  ExtensionRuntime.tsx         # Worker + Comlink 运行时
  ExtensionObjectRegistry.tsx  # 扩展实体渲染/点击注册表
  ExtensionKeyBindManager.tsx  # 扩展快捷键
  ExtensionUtils.tsx           # MIME 等工具
  api/host.tsx                 # Host API（主线程暴露给 Worker）
  api/remote.tsx               # Remote API 类型
  setupComlink/                # Comlink 传输处理器定制
packages/extprg/               # CLI 构建/打包/安装/开发
packages/extprg-types/         # 扩展 API 类型声明
packages/create-extprg/        # 脚手架
```

## 1. 扩展包格式

扩展也是 `.prg`（或开发态目录），容器内容：

```text
extension.js       # esbuild 打包的 ESM 代码（Worker 内执行）
metadata.msgpack   # { version, extension: { id, name, version, description, author } }
README.md          # 扩展说明
icon.svg/png/webp/jpg   # 图标（可选）
```

`TabFactory` 根据 `extension.js` 是否存在识别扩展。

## 2. Extension（扩展标签页）

继承 `Tab`：

- 解析 zip 或目录两种形态（目录时自动按 metadata.id 重命名不匹配的文件夹/文件名）；
- 提供管理 UI：元数据、README（Markdown 渲染）、启用/禁用、卸载、快捷键列表（`ext:<id>:` 前缀）、图标展示；
- 安装：从 zip 复制到 `appDataDir()/extensions/`；
- `Settings.disabledExtensions` 控制禁用列表。

## 3. ExtensionManager

- `getExtensions()`：列出 `appDataDir()/extensions/` 目录；
- `getExtension(name)`：缓存化加载；
- `getRuntime(name)`：创建 `ExtensionRuntime` 并缓存；
- `init()`：启动时加载所有未禁用扩展；
- `unload(name)`：终止 Worker 并清缓存；`reload()`：全部终止后重载。

## 4. ExtensionRuntime（Worker + Comlink）

```text
把 comlink.min.js 与 setupComlink/remote 代码拼成 Worker 模块
Worker 内：self.prg = Comlink.wrap(self)  → 拿到 Host API 代理
主线程：expose(extensionHostApiFactory(extension), worker)
        → 扩展代码可调用 prg.* 全部宿主能力
remote = wrap(worker) → 主线程可反向调用扩展导出（如渲染函数）
```

`setupComlink` 定制传输处理器：

- `AUTO_PROXY`：非普通对象自动转 MessagePort 代理（数组逐项代理）；
- `CUSTOM_TYPES`：URI、Color、Vector、Rectangle 等自定义类型序列化；
- 事件回调（`proxy(project)`）：让扩展能订阅 Project 事件（on/off/emit）。

## 5. Host API（api/host.tsx）

扩展可用的能力（`self.prg`，完整签名见 `packages/extprg-types` 的 `ExtensionHostApi`）：

| 分类        | API                                                                                                                                  |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 提示        | toast / toast_success / toast_error / toast_warning                                                                                  |
| 对话框      | dialog_confirm / dialog_input / dialog_copy / dialog_buttons                                                                         |
| 网络        | fetch / fetch_base64 / fetch_json / fetch_binary                                                                                     |
| 系统        | shell_execute（Rust `run_command`）                                                                                                  |
| 设置        | settings_getOwn/setOwn（扩展私有）、settings_getGlobal/setGlobal（敏感项禁用：aiApiKey、aiApiBaseUrl）                               |
| 快捷键      | keybinds_register（经 ExtensionKeyBindManager，持久化 keybinds2.json）/ keybinds_unregisterAll                                       |
| 主题        | themes_register（注册扩展主题，`Themes.registerExtensionTheme`）                                                                     |
| 标签页/工程 | tabs_getAll / tabs_getAllProjects / tabs_getCurrent / tabs_getCurrentProject（返回 Comlink 代理对象，可直接操作 Project 方法与事件） |
| 扩展实体    | entity_registerType（配置 + 渲染函数）/ entity_onClick（点击回调）/ entity_create（创建实例）                                        |
| 表单        | form（JSON Schema → zod → 子窗口表单，返回表单值）                                                                                   |

注意：扩展拿到的 `Project`/`Tab` 是 Comlink 代理，跨线程调用其方法（如 `project.stageManager.add(...)`）、订阅事件（`on/off/emit`）均可；Host API 只有上表这些入口，没有直接的 AI 对话/子窗口创建 API。

## 6. 扩展实体（ExtensionEntity）

- `stageObject/entity/ExtensionEntity.tsx`：通用扩展实体，配置含尺寸/缩放模式；
- `ExtensionObjectRegistry`：`registerType(extensionId, typeName, config, renderFn)` 与 `registerClickHandler`；
- 渲染：主线程请求 Worker 的渲染函数（返回 ImageBitmap/OffscreenCanvas），画布绘制；点击事件回传 payload（相对/绝对世界坐标 + customData + uuid）；
- `ControllerExtensionEntityClick` 负责画布侧点击转发。

## 7. 扩展快捷键

`ExtensionKeyBindManager`：

- id 规范 `ext:<extensionId>:<id>`；
- 默认键写入 `keybinds2.json`，用户可在设置页改键/禁用（`KeyBindsUI` 统一管理）；
- 跨平台键位转换（Win → Mac）；
- 卸载/禁用时 `unregisterAll(extensionId)`。

## 8. 工具链（packages/extprg）

`extprg` CLI（cac）：

| 命令             | 行为                                                                                                                |
| ---------------- | ------------------------------------------------------------------------------------------------------------------- |
| `extprg build`   | esbuild 打包 `src/extension.ts` → `dist/extension.js`；生成 `metadata.msgpack`（读 package.json）；复制 README/icon |
| `extprg package` | 打 zip（含 icon 等）                                                                                                |
| `extprg install` | 安装到应用扩展目录（按 `--app-id` 定位）                                                                            |
| `extprg dev`     | 开发模式（构建 + 安装 + 监听）                                                                                      |

`create-extprg` 提供脚手架模板（package.json.ejs、extension.ts.ejs、tsdown.config.ts.ejs 等）。

## 9. 安全边界

- 扩展在 Worker 中运行，无法直接访问 DOM/React；
- 所有能力必须通过 `prg` API 代理，主线程侧对敏感设置做白名单/黑名单；
- MCP 工具与扩展命令调用有审批/校验（Rust `mcp.rs` 校验命令参数、`shell.rs` 同步执行并返回码）。
