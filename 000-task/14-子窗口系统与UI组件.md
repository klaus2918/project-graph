# 14 子窗口系统与 UI 组件

## 1. 子窗口系统

Project Graph 不使用浏览器多窗口，而是**自研子窗口/面板系统**：每个子窗口是一个 `ComponentTab`，可悬浮（floating，可拖拽/缩放/置顶）或停靠（docked，进入标签布局树）。

### 1.1 核心文件

```text
app/src/core/subWindowOpen.ts       # 子窗口创建工厂
app/src/core/subWindowOpenModes.ts  # 窗口 ID 清单 + 默认打开模式
app/src/core/TabWorkspace.tsx       # 布局管理（见第 03 篇）
app/src/components/floating-tabs.tsx  # 悬浮窗口渲染
app/src/components/docked-area.tsx    # 停靠区渲染
```

### 1.2 打开模式

每个子窗口可配置四种模式：

```text
floating     悬浮窗口
docked       停靠到当前活动组
dockedLeft   停靠到固定左组（pg-side-left）
dockedRight  停靠到固定右组（pg-side-right）
```

默认配置见 `subWindowOpenModes.ts` 的 `DEFAULT_SUB_WINDOW_OPEN_MODES`，用户可在“设置 → 自定义 → 窗口打开方式”修改（`Settings.subWindowOpenModes`）。

### 1.3 子窗口清单（SUB_WINDOW_IDS）

| 类别 | 窗口                                                                                                                        |
| ---- | --------------------------------------------------------------------------------------------------------------------------- |
| AI   | AIWindow（对话）、AIToolsWindow（工具/MCP）、AutoCompleteWindow                                                             |
| 导航 | OutlineWindow（大纲）、FindWindow（搜索）、RecentFilesWindow、KeyboardRecentFilesWindow、ReferencesWindow                   |
| 编辑 | NodeDetailsWindow（详情）、LatexEditWindow、EditUrlNodeLinkWindow、TagWindow、LittleTagWindow、FormWindow、TextImportWindow |
| 生成 | GenerateNodeTree / GenerateNodeTreeByMarkdown / GenerateNodeGraph / GenerateNodeMermaid、AutoComputeWindow（逻辑节点）      |
| 外观 | ColorWindow、ColorPaletteWindow、BackgroundManagerWindow、ExportPngWindow、NewExportPngWindow                               |
| 协作 | CollaborationWindow                                                                                                         |
| 系统 | SettingsWindow、OnboardingWindow、WelcomeWindow、TestWindow                                                                 |

另有 `AIRequestTraceView` 等视图组件按需作为标签打开，不在 `SUB_WINDOW_IDS` 清单内。

### 2.2 富文本编辑器（components/editor）

基于 Plate（Slate）：

- `editor-base-kit.tsx` + `plugins/*-base-kit.tsx`：基础能力（段落、标题、粗斜体、列表、表格、代码块、数学、媒体、链接、mention、callout、comment、suggestion、日期、toc、toggle、列布局、缩进、对齐、字体、行高、Markdown 语法）；
- `plugins/*-kit.tsx`：与 `components/ui/*-node.tsx` 对应的 UI 渲染；
- `transforms.ts`：编辑器变换工具；
- UI 侧对应大量 `*-node.tsx / *-toolbar.tsx / *-toolbar-button.tsx`（shadcn 风格）。

节点详情（NodeDetailsWindow）与文本节点编辑复用该编辑器。

### 2.3 shadcn/ui 组件库（components/ui）

`components.json` 管理：button、dialog、dropdown-menu、context-menu、popover、select、tabs、tooltip、slider、switch、checkbox、input、textarea、sheet、sidebar、table、tree、command、avatar、badge、card、scroll-area、separator、skeleton、sonner（toast）、alert、alert-dialog、collapsible、calendar、field、label、progress、resize-handle、key-bind 等。

## 3. 语言（i18n）

目录 `app/src/locales/`：

| 文件         | 语言       | 维护方式                                                           |
| ------------ | ---------- | ------------------------------------------------------------------ |
| `en.yml`     | 英文       | 手写                                                               |
| `zh_CN.yml`  | 简体中文   | 手写                                                               |
| `zh_TW.yml`  | 普通繁体   | **由 zh_CN 自动生成（vite 插件 i18n-auto-tw + OpenCC），禁止手改** |
| `zh_TWC.yml` | 接地气繁体 | 手写                                                               |
| `id.yml`     | 印尼语     | 手写                                                               |

`main.tsx` 动态 import 全部语言文件初始化 i18next；新增文案需同步 en/zh_CN（及必要时的 zh_TWC/id），运行 `pnpm --filter @graphif/project-graph sync-locales` 生成 zh_TW。

## 4. 主题与样式入口

- `css/index.css`：全局样式（Tailwind v4）；
- 主题变量：`<style id="pg-theme">` 注入 `--*` CSS 变量（见第 12 篇）；
- UI 缩放：`Settings.uiScalePercent` → `zoom` 样式只作用于 UI 层。

## 5. 设置窗口（sub/SettingsWindow）

页面结构：

```text
settings.tsx        主设置（通用/画布/交互…）
keybinds.tsx        快捷键设置（按分组）
keybindsGlobal.tsx  全局快捷键
local-ai.tsx        AI 本地模型/MCP 配置
extensions.tsx      扩展管理
account.tsx         账户
themes/index.tsx    主题选择
customization/      自定义：context-menu / global-menu / pie-menu / quick-settings /
                    window-open-modes / effects / sounds
about.tsx / credits.tsx
```
