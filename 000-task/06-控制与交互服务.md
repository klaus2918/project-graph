# 06 控制与交互服务

相关目录：`app/src/core/service/controlService/`

```text
controlService/
  MouseLocation.tsx                # 全局鼠标位置单例
  controller/                      # 控制器主类 + 具体控制器
    Controller.tsx                 # 总控制器（事件绑定、按键集合、触摸）
    ControllerClass.tsx            # 具体控制器基类（事件绑定/解绑、view 坐标代理、双击检测）
    concrete/                      # 16 个具体控制器
    utils/ShakeDetector.ts         # 摇晃检测
  stageMouseInteractionCore/       # 鼠标悬停命中状态
  rectangleSelectEngine/           # 框选
  keyboardOnlyEngine/              # 纯键盘操作引擎
  DirectionKeyUtilsEngine/         # 方向键工具
  shortcutKeysEngine/              # 快捷键注册/UI 管理/全局快捷键
  autoLayoutEngine/                # 自动布局（DAG + 快速树）
```

## 1. 控制器体系

### 1.1 Controller（总控制器）

`@service("controller")`，职责：

- 绑定 canvas 事件：keydown/keyup、pointerdown/up、touchstart/move/end、wheel、pointerleave；
- 维护 `pressingKeySet`（当前按键集合）、`isMouseDown[3]`、`lastClickTime/Location`、`touchStartLocation/Distance/Delta`；
- 阻止浏览器默认行为（Ctrl+F/G、F3/F5/F7、R、P、J 等）；
- 双指触摸：缩放（距离比）+ 平移（中心位移）；
- 自动发现并实例化 `./concrete/*.tsx` 中所有 `*Class` 导出：`import.meta.glob` 扫描，按类名生成 `controller.<camelName>` 属性（如 `controller.camera`、`controller.nodeEdit`）；
- `isManipulateOverTime()` 供渲染器决定是否暂停重渲染。

### 1.2 ControllerClass（具体控制器基类）

每个具体控制器继承它：

- 延迟 10ms 绑定全部事件（等待 canvas 挂载完成）；
- `toViewEvent`：用 Proxy 把事件 clientX/Y 转换为画布逻辑坐标（`canvas.clientToView`）；
- `mouseup` 内检测双击（300ms/20px 阈值）调用 `mouseDoubleClick`；
- viewerMode 下默认拒绝交互（`allowViewerModeInteraction` 可覆盖）；
- `dispose()` 完整解绑。

## 2. 悬停命中（stageMouseInteractionCore）

`MouseInteraction` 服务维护鼠标悬停集合：

- `hoverEdges` / `hoverSections` / `hoverConnectPoints` / `hoverMultiTargetEdges`；
- `updateByMouseMove(worldLocation)` 遍历边/Section/连接点碰撞箱更新集合；
- 被折叠 Section 隐藏或大标题遮挡的对象排除在悬停外。

## 3. 框选（rectangleSelectEngine）

支持左右键两种触发与两种模式（`intersect` 相交 / `contain` 包含），配合 `Settings.rectangleSelectWhenLeft/Right`；框选过程调用 `Effects` 产生视觉反馈。

## 4. 纯键盘操作（keyboardOnlyEngine）

目标：不依赖鼠标完成大部分操作（类 XMind 体验）。

| 文件                                                  | 职责                                         |
| ----------------------------------------------------- | -------------------------------------------- |
| `keyboardOnlyEngine.tsx`                              | 主引擎                                       |
| `keyboardOnlyGraphEngine.tsx`                         | 图模式导航（上下左右移动选中、Tab 生长节点） |
| `keyboardOnlyTreeEngine.tsx`                          | 树模式导航                                   |
| `selectChangeEngine.tsx`                              | 选中变化引擎                                 |
| `newTargetLocationSelector.tsx`                       | 新目标位置选择                               |
| `DirectionKeyUtilsEngine/directionKeyUtilsEngine.tsx` | 方向键通用工具                               |

设计要点（README）：方向键移动选中实体；未选中时选择距屏幕中心最近的实体；Tab 按住显示虚拟位置、松开生长节点；虚拟位置在节点上则生成连线。

## 5. 快捷键系统（shortcutKeysEngine）

### 5.1 注册表（shortcutKeysRegister.tsx）

- `allKeyBinds`：全局快捷键定义表（id、默认键、when 条件、onPress）；
- `KeyBindWhen` 类型：按焦点状态/资源类型判断可执行性；
- UI 快捷键分组由 `sub/SettingsWindow/keybinds.tsx` 提供（设置页展示）。

### 5.2 KeyBindsUI

UI 级快捷键运行时：

- `registerOneUIKeyBind / unregisterOneUIKeyBind / registerAllUIKeyBinds`；
- 事件队列（最多 20 个）支持组合键/连续键（isContinuous + onRelease）；
- `inputInterceptors`：输入拦截器（AI 输入框等优先消费键盘事件）；
- 响应式 Hook `use(filter)`：设置页/扩展管理页实时展示快捷键；
- 跨平台键位转换（`utils/emacs.ts`：Win 键位 → Mac）；
- 持久化：`keybinds2.json`（Tauri store），`ShortcutKeyFixer` 修复历史坏数据；
- `KeyBindHintEngine`：画布上的按键提示渲染（renderer 调用）；
- 扩展快捷键注册统一走 `ExtensionKeyBindManager`（id 前缀 `ext:<extensionId>:`）。

### 5.3 全局快捷键（GlobalShortcutManager）

基于 `@tauri-apps/plugin-global-shortcut`：

- `Alt+1` 呼出窗口；`Alt+2` 切换窗口点击穿透；
- `allowGlobalHotKeys` 设置开关，变更时统一重注册/注销。

## 6. 自动布局（autoLayoutEngine）

| 文件                         | 职责                                                                                                |
| ---------------------------- | --------------------------------------------------------------------------------------------------- |
| `mainTick.tsx`               | `AutoLayout`：DAG 布局（拓扑排序分层 → 层内定距 → 保留首节点位置），`AutoLayoutFastTree` 快速树布局 |
| `autoLayoutFastTreeMode.tsx` | 快速树模式（树生成/展开时调用）                                                                     |

入口：`AutoLayout` 服务（`project.autoLayout`），从选中实体构建节点/边输入，输出新位置并移动；`LayoutManager`（stageManager 侧）执行落位。

## 7. 设置联动

控制相关设置项（节选，完整见 `Settings.tsx` schema）：

- 鼠标：`mouseLeftMode`（selectAndMove/draw/connectAndCut）、`mouseRightDragBackground`（cut/moveCamera）、`mouseWheelMode` 及 Shift/Ctrl/Alt 组合模式、`mouseSideWheelMode`；
- 相机：`moveAmplitude/moveFriction/scaleExponent`、缩放极限行为、`scaleCameraByMouseLocation`；
- 文本编辑：`textNodeStartEditMode`、换行/退出键、粘贴大小调整；
- 树生成：`autoLayoutWhenTreeGenerate`、`treeGenerateCameraBehavior`、Tab/反斜杠生成；
- 其他：`enableDragAutoAlign`、`enableEntityCollision`、`allowAddCycleEdge`、`gamepadDeadzone`（手柄预留）。
