# 12 反馈表现与主题

相关目录：`app/src/core/service/feedbackService/` 与 `app/src/themes/`

## 1. 特效引擎（effectEngine）

### 1.1 架构

```text
Effect（抽象：timeProgress + delay + subEffects）
  ├── tick(project)   # 进度推进/回退 + 子特效
  └── render(project) # 每帧绘制
Effects（@service("effects")，每工程唯一）
  ├── addEffect / addEffects（按 Settings.effectsPerferences 过滤）
  └── tick()          # 清理过期特效并逐帧 tick+render
```

设计取舍（README）：特效自带渲染方法，而不是“渲染与数据分离”，避免拆分后需要又长又丑的 if/switch 分发。

### 1.2 基础工具

- `effectObject.tsx`：Effect 基类（ProgressNumber 时间进度，0→max 正放，超时回放）；
- `effectMachine.tsx`：特效管理器；
- `effectParticle.tsx`：粒子元素；
- `mathTools/`：`easings`（缓动函数）、`animateFunctions`、`rateFunctions`；

### 1.3 具体特效（concrete/，约 25 个）

| 类别      | 特效                                                                                                                                                                  |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 实体反馈  | EntityCreateFlash、EntityShake、EntityJumpMove、EntityShrink、EntityAlign、EntityDashTip、NodeMoveShadow                                                              |
| 矩形/卡片 | RectangleFade、RectangleNote、RectangleNoteReversed、RectangleLittleNote、RectanglePushIn、RectangleRender、RectangleSlide、RectangleSplitTwoPart、RectangleTransform |
| 线条/切割 | LineEffect、LineCuttingEffect、EdgeCutEffect、ExplodeDashEffect、PenStrokeDeleted                                                                                     |
| 视觉      | ViewFlash、ViewOutlineFlash、CircleChangeRadius、CircleFlame、SparkBurst、TextRaiseLocated、MouseTipFeedback                                                          |

每个特效可在设置中单独开关（`effectsPerferences`）。

## 2. 舞台样式（stageStyle）

- `stageStyle.tsx`：`StageStyle` 数据类（画布背景、文本、细节调试色等）；
- `StageStyleManager`（`@service("stageStyleManager")`）：监听 `Settings.theme` 变化，从主题文件构建 `currentStyle`，渲染器读取它绘制画布元素。

注意：这是 **Canvas 舞台样式**，不是 UI 层的 Tailwind 主题。

## 3. 颜色管理（ColorManager / colorSmartTools）

- `ColorManager.tsx`：全局颜色数据初始化（`init()` 于 main.tsx 调用），供调色板子窗口使用；
- `dataManageService/colorSmartTools.tsx`：自动配色；
- `StageObjectColorManager`：对象颜色修改；
- `Color` 类型来自 `@graphif/data-structures`（RGBA 四元组）。

## 4. 音效（SoundService）

- `SoundService.tsx`：统一音效播放（`SoundService.play.viewAdjustSoundFile()` 等）；
- 音效文件路径可配置（`cuttingLineStartSoundFile` 等设置项）；
- `soundEnabled` 总开关（当前主流程中 init 被注释，处于预留/按需启用状态）。

## 5. 主题系统（Themes）

### 5.1 主题文件

`app/src/themes/*.yml`（YAML + frontmatter）：

```text
light.yml / dark.yml / dark-blue.yml / macaron.yml / morandi.yml / park.yml
catppuccin-latte / catppuccin-frappe / catppuccin-macchiato / catppuccin-mocha
```

frontmatter：`id / type(light|dark) / name / description`；content 为嵌套 CSS 变量对象。

### 5.2 机制

- `Themes.builtinThemes`：`import.meta.glob` 运行时收集 + YAML 解析；
- `convertThemeToCSS`：递归对象 → `--kebab-case` CSS 变量；
- `applyThemeById / applyTheme`：写入 `<style id="pg-theme">`，`color-scheme` 跟随主题类型；
- 扩展主题：`registerExtensionTheme`（扩展可注入主题，设置页按扩展分组）；
- `Settings.lightTheme / darkTheme / themeMode` 联动：App 监听切换。

## 6. 相关设置

- 特效开关、`autoFillNodeColor/PenStrokeColor/EdgeColor`（新建对象自动配色）、`colorPanelMouseEnterPreview`；
- `soundEnabled` 与各音效文件；
- 舞台渲染样式：`showBackgroundHorizontalLines/VerticalLines/Dots/Cartesian`、`showTextNodeBorder`、`sectionBitTitleRenderType`、`antialiasing` 等。

## 7. 其他反馈相关全局服务

- `AssetsRepository.tsx`：全局资源仓库（音效/图片等静态资产，快捷键提示与特效引用）；
- `SettingsIcons.tsx`：设置项图标映射；
- `QuickSettingsManager.tsx`：右侧快捷设置工具栏状态（启动时初始化）。
