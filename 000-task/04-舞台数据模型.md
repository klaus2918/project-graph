## 1. 继承体系

```text
StageObject（一切舞台对象的基类：uuid、collisionBox、isSelected、isPhysical、_isSyncing）
├── Entity（可移动、可放进 Section、有 details 富文本）
│   ├── ConnectableEntity（可被 Edge 连接、参与图分析，geometryCenter）
│   │   ├── TextNode         文本节点
│   │   ├── Section          分组框（可嵌套，本身也可被连接）
│   │   ├── ImageNode        图片节点（isBackground 背景图）
│   │   ├── UrlNode          链接节点
│   │   ├── SvgNode          SVG 节点
│   │   ├── LatexNode        公式节点
│   │   └── ConnectPoint     连接点
│   ├── PenStroke            笔迹
│   ├── ReferenceBlockNode   引用块
│   └── ExtensionEntity      扩展自定义实体（渲染由扩展提供）
└── Association（连接关系）
    ├── ConnectableAssociation（source/target 语义）
    │   └── Edge             边基类
    │       ├── LineEdge                     直线边（支持双向/平行偏移 shiftingIndex）
    │       ├── ArcEdge                      弧线边
    │       └── CubicCatmullRomSplineEdge    三次 Catmull-Rom 样条边
    ├── MutiTargetUndirectedEdge  多目标无向边
    └── SyncAssociation            数据同步关系（isPhysical=false）
```

## 2. StageObject 基类

- `uuid`：唯一标识（反序列化时用 `@id` 装饰器登记引用）；
- `collisionBox`：碰撞箱（一组 Shape 的集合），命中检测/框选/碰撞都依赖它；
- `isPhysical`：物理存在性（SyncAssociation 等纯数据对象为 false，排除在框选/删除/F 键重置之外）；
- `isSelected`：选中状态；
- `_isSyncing`：同步写入标记，防止 `StageSyncAssociationManager` 循环同步。

## 3. Entity

抽象能力：

- `move(delta)` / `moveTo(location)`（子类实现）；
- `details: Value`（Plate 富文本），`DetailsManager`（`tools/entityDetailsManager.tsx`）封装详情编辑/序列化/导出 Markdown；
- `parentSection` / `sectionDepth` / `nearestLockedAncestorSection`：运行时 Section 树信息（不序列化，由 `updateReferences()` 重建）；
- `updateFatherSectionByMove()`：移动时递归调整父 Section 位置大小并调用碰撞求解器；
- `updateOtherEntityLocationByMove()` / `collideWithOtherEntity()`：实体碰撞推开（`Settings.isEnableEntityCollision`）；
- `detailsButtonRectangle()` / `referenceButtonCircle()`：详情按钮与引用按钮的命中区域；
- `isHiddenBySectionCollapse`：是否被折叠的 Section 隐藏。

## 4. 实体类型速览

| 实体               | 关键特征                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------- |
| TextNode           | 文本、字体缩放（fontScaleLevel）、sizeAdjust 模式、自动换行、树形输入                         |
| Section            | 分组框：可嵌套、折叠（折叠后显示大标题）、拖拽进出、打包/解包、标题渲染模式（none/top/cover） |
| ImageNode          | 附件引用（attachmentId）、背景图模式、缩放、压缩为 WebP                                       |
| UrlNode            | 标题 + URL，双击/中键打开                                                                     |
| SvgNode            | 内嵌 SVG 数据                                                                                 |
| LatexNode          | KaTeX 公式渲染                                                                                |
| PenStroke          | 手绘笔迹（PenStrokeSegment），支持橡皮擦/切割                                                 |
| ConnectPoint       | 连线锚点（无文本）                                                                            |
| ReferenceBlockNode | 引用其他文件/Section 的块                                                                     |
| ExtensionEntity    | 扩展实体：配置（尺寸/缩放模式等）+ 扩展提供的渲染函数与点击处理                               |

## 5. 关联（Association / Edge）

- `Association.associationList: StageObject[]`（通用关系列表）；
- `ConnectableAssociation` 提供 `source = list[0]`、`target = list[1]`、`reverse()`；
- `Edge` 派生类提供 `text`（边文字）、`sourceRectangleRate/targetRectangleRate`（端点相对位置）、`shiftingIndex`（平行边偏移序号，由 `updateReferences()` 按几何组分配）；
- 多目标边 `MutiTargetUndirectedEdge`：一个源连接多个目标；
- `SyncAssociation`：节点间数据同步关系（颜色/文本等），由 `StageSyncAssociationManager` 驱动，`_isSyncing` 防循环。

## 6. 碰撞箱（collisionBox）

`CollisionBox` 持有 `Shape[]`（来自 `@graphif/shapes`：Rectangle/Circle/Curve/Line），提供：

- `getRectangle()` 外接矩形；
- `isContainsPoint()` 命中；
- 与矩形/线段/图形的相交检测；
- `EdgeCollisionBoxGetter`（`association/EdgeCollisionBoxGetter.tsx`）在启动时初始化，为各类边生成统一命中箱。

## 7. Camera（相机）

物理模型：把相机想象成带惯性/摩擦的飞行器。

- `location`（世界坐标）、`speed`、`accelerateCommander`（WASD 推力）；
- `currentScale / targetScale`：指数趋近式缩放（`Settings.scaleExponent`），缩放保持鼠标位置不动（`scaleCameraByMouseLocation`）；
- `frictionExponent = 1.5`，摩擦 `f = -k·v^1.5`，推力与 `1/scale²` 成正比（宏观快、微观慢）；
- `bombMove / pageMove`：PageUp/Down 式翻页（easeOutExpo 40 帧轨迹队列）；
- `reset / resetBySelected / resetByRectangle / resetScale / resetLocationToZero`：视野重置；
- `saveCameraState / restoreCameraState`：编辑节点等场景临时锁定视角；
- 极值保护：缩放越界时按 `cameraZoomIn/OutLimitBehavior`（macro/micro/reset）处理，NaN 自动重置并 toast。

## 8. Canvas

- 封装 `HTMLCanvasElement` + `ctx`；
- 监听 mousemove 唤醒渲染循环（菜单弹出时跳过）；
- 键盘事件重定向：把 `window` 键盘事件转派到 canvas（避免焦点问题），聚焦 input/textarea/contenteditable 时不转发；
- 阻止 Ctrl+F/G/R、F3/F5/F7 等浏览器默认行为；
- `mount(wrapper)`：ResizeObserver 监听容器尺寸 → `renderer.resizeWindow`；
- `clientToView / viewToClient`：客户端坐标与画布逻辑坐标互转（考虑 devicePixelRatio 与 CSS 缩放）。

## 9. StageManager 与具体管理器

### 9.1 StageManager（`stageManager/StageManager.tsx`）

舞台操作总入口：

- 查询：`get(uuid)`、`getEntities()/getSections()/getEdges()/getLineEdges()/getCrEdges()/getArcEdges()/getPenStrokes()/getImageNodes()/getSvgNodes()/getLatexNodes()/getUrlNodes()/getConnectPoints()` 等；
- 修改：`add(stageObject, skipUpdateReferences?)`、`delete(stageObject)`；
- 选中：`clearSelectAll/getSelectedEntities/…`；
- 运行时缓存：`rootSections`（根 Section 列表）、`topLevelEntities`（顶层实体）、`normalizedCrossParentRelationCount`；
- `updateReferences()`：修复 unknown 实体引用、重建 Section 运行时树（自动归一化交叉父级）、为直线边分配平行偏移索引（按端点矩形位置分组，双向边合并）。

## 10. 历史记录（StageHistoryManager）

两种实现（抽象类 `HistoryManagerAbs`）：

- `HistoryManagerTimeEfficient`：每次 `recordStep()` 保存**完整舞台序列化快照**，指针式前进/后退，受 `Settings.historySize`（默认 150）限制；
- `HistoryManagerMemoryEfficient`（同文件内，通过开关选择）：使用 jsondiffpatch 增量存储。

`undo/redo` 后直接替换 `project.stage` 并 `updateReferences()`；debug 模式展示历史位置/长度/内存估算 toast。协作服务应用远端数据时会 `clearHistory()`。

## 11. ProjectUpgrader

- `NLatestVersion = "2.6.0"`；
- 1.x JSON 格式：`upgradeVAnyToVLatest` 逐级 V1→V17；
- 2.x 起为 ZIP+MsgPack 格式，`upgradeNAnyToNLatest` 处理 N 系列升级；
- 升级不可逆，打开旧文件前弹确认框。
