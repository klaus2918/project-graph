## 2. 前置条件

- **cmake**：`D:\mysoft\cmake-portable\cmake\data\bin\cmake.exe`（cmake 4.4.3，便携安装，未动系统环境）
  —— `sentencepiece-sys` 的 build script 需要 cmake，本机原无 cmake 且 winget 不可用。
- **本地打包配置覆盖**：`.op\changes\env-hang\tauri-build-local.json` = `{"bundle":{"createUpdaterArtifacts":false}}`
  —— **必须带**。仓库 `tauri.conf.json` 的 `createUpdaterArtifacts: true` 且配了 updater 公钥，本机没有
  `TAURI_SIGNING_PRIVATE_KEY`，会在**成功产出 NSIS 之后**死于签名步骤（exit 1）。该覆盖不改仓库配置。
- **执行方式**：用 `schtasks` 脱离对话会话运行。构建挂在对话终端上时，回合结束会被回收杀掉。

## 3. 操作序列

### ① 打包

```powershell
$repo = "D:\githup-workspace\project-graph"
$env:PATH = "D:\mysoft\cmake-portable\cmake\data\bin;" + $env:PATH
$env:TAURI_BUILD_ARGS = "--config $repo\.op\changes\env-hang\tauri-build-local.json"
Set-Location $repo
pnpm build        # 等价于 nx run-many -t build tauri:build
```

> ⚠️ 本仓库 `AGENTS.md` 禁止 Agent 跑构建命令，**这条须由用户本人执行**。
> 推荐走已建好的计划任务（脱离会话，输出落盘）：

```powershell
Start-ScheduledTask -TaskName 'PG-LocalBuild'     # 日志：.op\changes\env-hang\build.log
```

若中途出现 `os error 5`（`failed to remove file ...project-graph-ownership-helper.exe`）：
先 `Get-Process | ? { $_.Path -like "*project-graph*" }` 结束占用进程，再重跑。

### ② 校验产物

```powershell
Get-Item "D:\githup-workspace\project-graph\app\src-tauri\target\release\bundle\nsis\Project Graph_0.0.0-dev_x64-setup.exe" |
  Select-Object LastWriteTime, Length
```

时间戳变成今天即成功。

### ③ 安装

```powershell
# A. 走计划任务（脚本会等安装包时间戳刷新后 /S 静默安装）
Start-ScheduledTask -TaskName 'PG-LocalInstall'   # 日志：.op\changes\env-hang\install.log

# B. 手动装（会替换现有版本）
& "D:\githup-workspace\project-graph\app\src-tauri\target\release\bundle\nsis\Project Graph_0.0.0-dev_x64-setup.exe"
```

## 6. 本轮踩过的坑

| #   | 坑                                                                         | 处置                                                 |
| --- | -------------------------------------------------------------------------- | ---------------------------------------------------- |
| 1   | `sentencepiece-sys` 需要 cmake，本机无 cmake / winget                      | 便携 pip 安装 cmake 到 `D:\mysoft\cmake-portable`    |
| 2   | `createUpdaterArtifacts: true` + 无签名私钥 → 产出 NSIS 后 exit 1          | `--config` 局部覆盖关闭，不改仓库文件                |
| 3   | 构建挂在对话终端会话上 → 回合结束被回收杀掉（11:32 编译中断）              | 改用 `schtasks` 脱离会话执行                         |
| 4   | 无 BOM 的 UTF-8 `.ps1` 被 PS 5.1 按 ANSI 读 → `install-local.ps1` 解析失败 | 该脚本改纯 ASCII                                     |
| 5   | `os error 5` 删不掉 `project-graph-ownership-helper.exe`                   | 瞬时占用，确认无残留进程后原样重跑即通过             |
| 6   | 计划任务带 23:59 触发器，会在测试期间自动重构建 + 重装                     | 禁用触发器（`Enabled=False`），任务保留可手动 `/Run` |
